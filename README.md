# The Curiosity Club

A warm, editorial-style home for short, verified discoveries across all subjects.

## Current stage
This is the first visual website version. It contains sample cards for layout demonstration only.
The sample content is clearly labelled as illustrative and must not be presented as researched facts.

## Run locally
Open `public/index.html` in a browser.

## Deploy
Upload the contents of this folder to the root of your GitHub repository. Vercel can then serve the static site.

## Important publishing rule
Do not publish automatically generated factual content until the research retrieval, source validation,
evidence review, and publication gate have been implemented and tested. Every published claim must
have a working source link that directly supports it.
